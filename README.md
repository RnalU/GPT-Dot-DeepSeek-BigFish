# GPT-Dot-DeepSeek-BigFish

**DeepSeek 鲸鱼娘·趴圈版**：用于 ChatGPT Dot / Pet 的非官方同人形象与动画素材。蓝白圆环、上半身大脸表情，包含完整眨眼、拿笔画画和键盘动作。

本项目与 OpenAI、ChatGPT、DeepSeek 无官方关联，不代表任何品牌背书。

## 当前动作与状态

图集采用 v2 布局：1536 × 2288 像素，8 列、11 行，每格 192 × 208 像素。下表行号从 0 开始。

| 图集行 | 状态槽位 | 有效帧数 | 当前内容或用途 |
| --- | --- | ---: | --- |
| 0 | `idle` | 6 | 完整眨眼 |
| 1 | `running-right` | 8 | 向右移动 |
| 2 | `running-left` | 8 | 向左移动 |
| 3 | `waving` | 4 | 招手 |
| 4 | `jumping` | 5 | 跳跃 |
| 5 | `failed` | 8 | 失败反馈 |
| 6 | `waiting` | 6 | 等待反馈 |
| 7 | `running` / active work | 6 | 拿笔画画 |
| 8 | `review` | 6 | 键盘动作 |
| 9–10 | 视线姿态 | 共 16 | 不同方向的视线 |

**托腮目前只有静态概念设计，尚未纳入图集，也不是可独立触发的动画状态。** 当界面显示 Thinking 而头像在画画时，这与当前工作槽位的内容一致；不能据此断言客户端丢失了已实现的托腮动作，或选择了错误动作。

当前自定义配置没有额外的 `thinking` / `creating` 动画槽位，也没有可提交的逐帧时长或 FPS 字段。界面状态文案与图集动画槽位不应直接视为一一对应。

## 播放节奏：预览与客户端配置

PNG 图集只保存图像，不携带逐帧播放时长。预览视频的编码节奏不等于运行端实际速度。

| 项目 | 每帧时长（毫秒） | 一轮合计 | 证据性质 |
| --- | --- | ---: | --- |
| 眨眼制作预览 | 280 / 110 / 110 / 140 / 140 / 320 | 1.10 秒 | 制作预览节奏 |
| 画画制作预览 | 120 / 120 / 120 / 120 / 120 / 220 | 0.82 秒 | 制作预览节奏 |
| 已检查客户端的 `idle` | 1680 / 660 / 660 / 840 / 840 / 1920 | 6.60 秒 | 安装代码配置 |
| 已检查客户端的 `running` | 120 / 120 / 120 / 120 / 120 / 220 | 0.82 秒 | 安装代码配置 |
| 已检查客户端的 `review` | 150 / 150 / 150 / 150 / 150 / 280 | 1.03 秒 | 安装代码配置 |

2026-10-07 对已安装的 Linux ChatGPT 42.3.0 客户端资源进行只读检查：其 Pet 渲染器保存了合计 1.10 秒的基础待机序列，但 `idle` 分支实际选择的是每帧时长乘以 **6** 的慢速序列，配置总时长因此为 **6.60 秒**。帧推进使用逐帧定时器。

这说明该版本代码中存在慢眨眼机制，但**尚未对当前 Dot 页面实际采用的渲染路径或屏幕帧间隔进行测量**。6.60 秒是所检查代码的配置值，不能写成当前 Dot 的实测结果；系统调度、动态状态和渲染路径也可能影响实际观感。单张截图无法证明动画播放速度。

## 使用说明

1. 获取仓库中的最终 PNG 图集与配套 manifest，保留原始尺寸、透明背景和网格排列。
2. 在支持自定义 Pet 的 ChatGPT / Dot 入口中导入图集，并选择生成的自定义形象。具体入口和可用性以当前客户端为准。
3. 按上表核对眨眼、工作、Review 与视线效果；预览视频用于查看动作内容和制作节奏。
4. Dot 的头像选择与 Work / Codex 的全局 Pet 选择可能独立。请在目标使用界面确认选中了所需形象。

manifest 用于描述素材与状态映射，不意味着客户端会读取其中的任意自定义时序字段。不要为调整播放速度修改客户端安装文件；本项目没有提供这类修改。
